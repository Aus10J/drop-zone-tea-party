Sales Limits

3
drinks per CAC
per night

Every scanned CAC carries its own running count for the night. When a patron reaches this number the sale stops, and a manager has to override it with a PIN and a written reason that gets recorded against the order.

Counted in drinks served — one pour is one drink whether it is a 4.6% lager or a 7% IPA.

Category caps

Each category has its own cap underneath the night total, and whichever runs out first wins. With a total of 4 and liquor at 3, a patron can have four beers, or three liquors and a beer — but never a fourth liquor. Cocktails count against the liquor cap.

Backups

Everything lives in one file on this machine. Point this at a USB stick or a shared drive and a copy is taken automatically when a shift closes and once a day — so a dead disk costs you nothing.

Privacy & Records

Off means the app keeps only the card hash and drink counts — no names at all. Drink limits still work; the bartender just sees an ID, not a name.

The manager PIN is still the default 1234. Change it before opening.

Maintenance

Card Layout Calibration

Optional. Drink tracking already works without this — identity comes from a hash of the whole scan. Calibrate only if you want names and dates of birth to fill in automatically instead of typing them once per new patron. Scan a card you own, then set the start position and length of each field until the preview reads correctly.

Find the DoD ID for me

The barcode does not carry the ID as readable text, which is why a raw scan looks like nonsense. Scan your own card above, type your own DoD ID here, and the app will work out where it is hidden.
